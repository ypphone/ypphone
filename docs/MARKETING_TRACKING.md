# 천안본점 웹사이트 마케팅 구현

이 문서는 사이트 코드와 검증 방법을 기록한다. 공통 이벤트와 수집 원칙, UTM, 계정 경계와 배포 조합은 통합 마케팅 운영 문서를 기준으로 한다.

- [브라우저 추적 코드](../src/js/script.js)는 광고 파라미터 변환, 이벤트 분류와 전환 호출을 구현한다.
- [브라우저 설정](../src/js/marketing-config.js)은 페이지 실행에 필요한 공개 설정을 관리한다.
- 네이버 광고 파라미터 변환 시 기존 UTM과 네이버 원본 값을 보존한다. 매핑 규칙 변경은 공통 기준을 확인하고 반영한다.
- 전화·카카오·길찾기·네이버톡 링크를 검증할 때는 모의 제공자 응답을 사용한다. 로컬 미리보기에서는 외부 전환을 전송하지 않는다.
- 실제 게시 브랜치와 배포 상태는 GitHub Pages 설정과 성공한 배포 기록에서 확인한다.
